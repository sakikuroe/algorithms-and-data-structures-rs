# オンライン版の疎な遅延セグメント木

`SegmentTreeLazySparseOnline<M, F>` は、論理区間 `[0, len)` を更新端点で分割し、一様な区間を葉とする AVL 木で保持します。座標と区間長は `usize` で扱い、初期値はモノイドの単位元です。端点を事前登録する必要はありません。

`effect` で区間作用、`fold` で区間集約、`get` で点の値を取得できます。`max_right` と `min_left` は、集約値に対する単調な述語を使って境界を探索します。読み取りでは節点を追加しません。`F` は `RangeAction<M::S>` を実装する必要がありますが、`Default` や `Copy` は必要ありません。

保持する区間数を `K` とすると、区間更新と集約の時間計算量は `O(log(K + 1))` です。左右の境界探索では、条件を満たさなくなる葉の中を二分探索するため、`O(log(K + 1) + log(len + 1))` 時間になります。一様な葉の一部は、初期値からの作用を指定された区間長へ適用して集約します。

1 回の更新で新たに分割する端点は高々 2 個です。更新回数を `Q` とすると、葉の数は高々 `2Q + 1`、内部節点を含む節点数は高々 `4Q + 1` です。不要になった内部節点は再利用します。座標幅に応じた深い経路や、読み取りのための節点は作りません。

## 記憶領域と上限

子の節点番号には `u32` を使い、`u32::MAX` を子や部分木がないことを表す印に予約しています。確保できる節点数は最大 `u32::MAX` 個です。この上限に達し、再利用できる節点もない状態で追加の確保が必要な更新はパニックします。論理区間長や座標に対する `u32` の制限はありません。

作用は `Option<F>` で保持します。葉では初期値からの作用を、内部節点では子へ未伝播の作用を表します。作用の有無を管理するビット列や、未初期化領域の手動管理は使いません。必要なメモリーは集約値と作用の型、節点数、内部配列の確保容量に依存します。
