# オンライン版の疎な遅延セグメント木

`SegmentTreeLazySparseOnline<M, F>` は、論理区間 `[0, len)` のうち更新に必要な節点だけを保持します。座標と区間長は `usize` で扱い、初期値はモノイドの単位元です。

`effect` で区間作用、`fold` で区間集約、`get` で点の値を取得できます。`max_right` と `min_left` は、集約値に対する単調な述語を使って境界を探索します。読み取りでは節点を追加しません。`F` は `RangeAction<M::S>` を実装する必要がありますが、`Default` や `Copy` は必要ありません。

区間更新と集約、境界探索の時間計算量は `O(log(len + 1))` です。更新回数を `Q` とすると、保持する節点数は最悪 `O(Q log(len + 1))` になります。座標が広い場合、疎な木でも大量の節点を生成することがあります。

## 記憶領域と上限

子の節点番号には `u32` を使い、`u32::MAX` を未生成の印に予約しています。生成できる節点数は最大 `u32::MAX` 個です。この上限に達した後、さらに節点を生成する更新はパニックします。すでに生成した節点だけで処理できる更新と読み取りは、この上限に達していても行えます。論理区間長や座標に対する `u32` の制限はありません。

未伝播の作用の有無は節点ごとに 1 ビットで保持し、作用本体は初期化済みの節点についてだけ読み取り・破棄します。必要なメモリーは集約値と作用の型、生成節点数、内部配列の確保容量に依存します。作用型によっては `Option<F>` と `F` が同じ大きさなので、有無の分離による削減効果は型ごとに異なります。
